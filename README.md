**專門 RenaCrypt Pack & OMEGA Pack 設計的抽卡計數器**

/Start　直接抓取所有歷史數據  
/Stop　 停止；數據會擷取至停止當下  
/Reset　清除當前儲存數據  
/Setstart　從輸入日期和時間開始擷取數據，例如 2026-03-28 12:00（時間統一為 UTC+8，可直接輸入）

抽卡是「獨立隨機事件」（也就是每次抽取彼此獨立，且機率固定），那麼每一張卡牌在每一次抽取中的機率本質上是相同的，這種情況下，長期紀錄更多是用來驗證實際掉率是否接近理論值，或建立自己的心理預期，對於預測下一次結果的幫助其實有限。

但如果存在保底機制、動態機率（例如抽越多次未中機率越高）或其他未公開的權重調整，那麼抽卡的機率就不再是固定值，而會隨著歷史狀態改變。

在這種情況下，這類長期數據監控反而可能觀察出分佈異常或潛在規律，甚至用來推測機制是否存在。

總之，就是給大家增加一個心理預期。
